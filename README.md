# Qandeel & Qazi Runner

A simple endless runner game built with Pygame.

## Features

- Player jump controls with spacebar
- Random fly and snail obstacles
- Score that increases over time
- Background music and jump sound effects

## Requirements

- Python 3.14+
- `pygame-ce`

## Run

```bash
python "runner_class only.py"
```

If `pygame` is not available on your Python version, install `pygame-ce` instead:

```bash
python -m pip install pygame-ce
```

## Controls

- `SPACE`: Jump / start the game
- Close the window to quit
